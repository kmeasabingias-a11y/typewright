# TypeWright Code Walkthrough — Index

Plain-language explanations of every script in the TypeWright project. **One file per
script.** The goal: anyone — even someone new to Python or web services — can read a
walkthrough and understand what that script does and *why* it's written that way.

These are written to be **simpler and friendlier** than the Kestrel walkthroughs. Less
jargon, more everyday analogies, short sentences. When a term has to be used, it gets
explained.

**Phase 6 progress (Fix Suggestions — Units 1 & 2 done; mechanism complete):** the fourth and final LLM call proposes a corrected function and **proves** it. ## Maintenance rule (important)

This folder must stay in sync with the code. The rule:

> **Whenever a TypeWright script is created or modified, its walkthrough is created or
> updated in the same step.** If a change alters behavior, append a short dated note to
> that walkthrough's "Change history" section explaining what changed and why.

So a code change is not "done" until its walkthrough reflects it. The status table above
is the at-a-glance check: every code file should have a ✅ row, and that row's doc should
describe the *current* code, not an old version.

---

## The shape of each walkthrough

Every file follows the same skeleton, so once you've read one you know how to read them all:

1. **What this file is for** — one paragraph, with an everyday analogy.
2. **A mental model** — the one or two ideas you need before reading the code.
3. **The whole file** — the actual code, pasted in full.
4. **Step-by-step** — each part explained in plain language.
5. **What could go wrong** — the mistakes this code is written to avoid. (Often the most
   useful section — it shows *why* the code looks the way it does.)
6. **Change history** — dated notes, added whenever the script changes.

## How to use this folder

- Read in order (01, 02, 03…) for a guided tour of the whole codebase, or
- Jump to the file you're curious about.
- If you only read one section, read **"What could go wrong"** — that's where the real
  understanding lives.
